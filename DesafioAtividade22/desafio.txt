AXIOS
Axios é um pacote JavaScript usado para fazer requisições HTTP (GET,
POST, PUT, DELETE etc.) tanto no navegador quanto no Node.js, é baseado
em promises. É isomórfico (pode rodar no navegador e no node.js com a mesma
base de código). No lado do servidor usa o código nativo do node.js, o modulo
http, enquanto no lado do cliente (navegador) usa XMLHttpRequests29.
No exemplo a seguir, está sendo feita uma solicitação GET para a URL
“https://jsonplaceholder.typicode.com/posts/1” da API JSONPlaceholder e, em
seguida, manipulando a resposta e os erros potenciais.
JSONPlaceholder30 é um servidor de API REST fake (falso) online e
gratuito que é amplamente utilizado por desenvolvedores para testes e
prototipagem. Exemplo: ao invés de precisar configurar um backend complexo
ou um banco de dados para testar como seu frontend (aplicativo web ou mobile)
interage com uma API, o JSONPlaceholder oferece um conjunto de recursos e
rotas pré-definidos com dados JSON.
